perseids

        
Run every job in your GitHub Actions workflow at the same time, each on a fresh cloud machine, against your exact local commit. One exit code when it's done.

        
Install


git clone https://github.com/kkeeland/perseids ~/.perseids
ln -s ~/.perseids/bin/perseids /usr/local/bin/perseids

        
Needs bash, git, jq, curl, ssh and Ruby 2.6+. MIT licensed.

        
Add your Boat key


perseids key        # asks once, checks it with Boat, saves it with mode 600

        
Quick start


cd your-repo
perseids run        # every job in .github/workflows/ci.yml

        
Commands

        

          
CommandWhat it does

          
run [job...]Run the workflow, or only the named jobs. Each matrix entry gets its own machine.

          
exec '<cmd>'Run one command on one machine against your commit.

          
keySave your Boat API key.

          
ls · reapList your running machines. Delete ones left by a killed run.

        

        
Flags

        

          
FlagEffect

          
-w <file>Use another workflow file.

          
--keep-goingDon't stop a job at its first failing step.

          
--dirtyInclude uncommitted changes to tracked files.

        

        
Exit codes

        

          
CodeMeaning

          
0Every job passed.

          
1A job failed. The summary names the step and prints the end of its log.

          
2Incomplete. Something couldn't run on a machine (macOS, Windows, container jobs). Never reported as green.

          
99A machine failed, not your code. Run it again.

        

        
Configuration

        

          
VariableDefaultEffect

          
PERSEIDS_TYPElargeMachine size: large or xlarge.

          
PERSEIDS_MAX10Machines at once, up to your account limit.

          
PERSEIDS_TTL7200Seconds before a machine stops itself.

          
PERSEIDS_EVENTpushThe github.event_name your if: conditions see.

        

        
Limits

        
  • Linux jobs only. macOS, Windows and container: jobs are reported as skipped.
  • Secrets are never sent to machines. Steps that need one are skipped.
  • Reusable workflows aren't supported yet.

Quickstart

        
Run your existing GitHub Actions workflow on Perseids in about two minutes. You need a repo with a workflow in .github/workflows.

        
1 · Install


git clone https://github.com/kkeeland/perseids ~/.perseids
ln -s ~/.perseids/bin/perseids /usr/local/bin/perseids

        
2 · Add your Boat key

        
Create one in Boat under Settings, API keys. Perseids checks it and keeps it in ~/.config/perseids/boat.env.


perseids key

        
3 · Run

        
From the repo root. Perseids tests the current commit, so commit first or pass --dirty. It picks ci.yml, or the only workflow there is; choose another with -w.


perseids run

        
4 · Read the result

        
The last line is the verdict: exit 0 means every job passed. Full logs for each job are in ~/.local/state/perseids/logs.
